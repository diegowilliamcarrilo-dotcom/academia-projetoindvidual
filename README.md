# Sistema de Academia - Projeto Evolutivo Individual

## Descrição
Sistema desenvolvido em PHP utilizando os conceitos de Programação Orientada a Objetos (POO).

## Conceitos Aplicados
- Abstração
- Herança (`Aluno` e `Professor` herdando de `Pessoa`)
- Encapsulamento
- Polimorfismo

## Como Executar
No terminal da pasta do projeto, execute:
`php -S localhost:8000`
E acesse no navegador: `http://localhost:8000/index.php`
